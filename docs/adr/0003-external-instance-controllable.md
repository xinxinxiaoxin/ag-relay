# 外部网关保留停止 / 重启能力,刻意不采用设计稿的「外部实例只读」

设计稿(`ui-design-lab` 的 `DESIGN.md`)把外部实例画成只读(禁用停止 / 重启)。本项目**刻意反其道**:保留对**外部网关**的优雅停止与安全重启能力,与已上线并测试的 F1 行为(「关了就彻底关了」——无受管网关时面板的停止会优雅停掉端口上的外部网关、退出软件时亦然)保持一致。为安全起见,外部实例在 UI 上打醒目「外部实例」标记,破坏性操作加二次确认。

## Consequences

- 面板行为与设计稿文案不一致处,以本 ADR 为准(按「可操作 + 标记 + 二次确认」实现,而非「只读」)。
- 停止 / 重启对外部网关生效仍受既有安全约束(经 supervisor 父链核实,宁可不杀不可误杀)。
