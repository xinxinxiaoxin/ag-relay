# AG Relay 自主维护网关核心,不再整体覆盖外部项目快照

2026-10-12 确认:AG Relay 从桌面壳演进为包含网关核心与桌面面板的完整产品。本仓库接管现有随包网关核心的维护,核心与面板配套开发、测试和发布;不再以从 relay-retry-proxy 整体覆盖脚本作为常规升级方式。其他项目的改进可按需吸收并保留来源及许可要求,避免覆盖 AG Relay 自身的改动。

这一决定取代 [ADR-0002](0002-diagnostics-localization-shell-side.md) 中的「上游脚本零改动、只整体覆盖更新」边界,不推翻其诊断字段约束、中文展示职责和未知事件诚实回退原则。日志实时传递不再被限制为必须只读诊断文件,具体通道另行设计。

## Consequences

- 产品整合不要求重写已有网关能力,也不要求把核心与面板合并到同一进程;继续保留现有 Node 核心与桌面面板分工,优先复用现有测试。
- 核心配置、控制协议和诊断事件发生变化时,由 AG Relay 同步维护面板适配与契约测试,不再把兼容责任交给外部项目。
- 这是已确认的维护方向,不是已完成的代码迁移。README 的旧覆盖流程及其他维护文档须随实施更新;公开分发前仍须核实来源、许可证和敏感信息。
