# 诊断汉化由壳侧只读消费者完成,上游网关脚本零改动

> 2026-10-12:「上游脚本零改动、只整体覆盖更新」及实时传递只能经文件读取的边界已由 [ADR-0004](0004-owned-gateway-core.md) 取代。下文保留历史理由;诊断字段约束、中文展示职责和未知事件诚实回退原则仍适用。

网关的诊断记录是英文,用户看不懂。汉化**不在网关里做**(网关脚本是上游代码,按 README 流程只整体覆盖更新,改它会在每次升级时丢失),而是在壳侧新增一个**只读消费者**:增量读取诊断文件 → 按一张中文字典(以 `event` 加 `kind`/`source`/`refusal`/`terminalKind`/`stallReason`/`phase`/`status` 等稳定枚举为键)把诊断记录提炼成分级中文「活动事件」。数字 / UUID / 哈希等动态位直接透传。

## Consequences

- 字典须随上游新增的事件码维护;以一个契约测试(断言字典覆盖打包脚本当前会发的所有码)兜底,上游加码即变红。
- 未知码诚实回退(显示原始码),绝不隐藏或崩溃。
- 范围仅诊断文件(面板展示用);回给客户端的报错与 verbose 开发日志(含上游自由文本)不在此列。
- 只读、增量 tail、分页懒读,不触碰网关进程,不影响网关性能。
