# 可配置单上游连接,不新增账号与密钥托管

> 状态：已落实；连接设置与客户端密钥用法见 [README 快速开始](../../README.md#快速开始)，实现维护见 [网关核心维护说明](../gateway-core-maintenance.md)，下文保留原决策记录。

2026-10-12 确认:AG Relay 面向用户分发后,不能要求修改源码才能换用自己的上游服务。首版保留现有上游服务作为默认值,允许用户修改一个上游地址与本地端口,默认仍只接受本机连接;连接设置须持久保存,修改后明确提示需要重启网关,不得悄悄打断请求。

继续由客户端提供上游鉴权密钥,本轮不增加 AG Relay 的账号或密钥持久化托管,也不扩展多渠道、账号池或负载均衡。这是在可配置性与产品范围之间的明确取舍:补足普通用户安装后的基本使用能力,不引入另一套账号管理和凭据存储体系。请求处理必需的密钥透传不等同于账号托管,也不允许因此把密钥写入诊断记录。

此决定是已确认的产品边界,配置存储、校验和应用时机的实现仍待后续设计与测试。
