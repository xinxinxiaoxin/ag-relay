# AG Relay 按整体版本更新,安装不得强行中断请求

2026-10-12 确认:用户更新的对象是 AG Relay 自身发布的完整版本,包括网关核心与桌面面板,不是独立追踪原网关项目的最新代码。维护者在 GitHub 发布新版后,应用检查并提示,由用户确认下载与安装;这避免核心与面板各自升级造成配置、控制协议或诊断事件不兼容。

下载与安装应分开控制。Windows 更新安装会退出当前应用,因此只有满足安全停机条件后才可进入安装阶段;仍有请求时等待,超时则不安装、不强行掐断请求,让用户稍后重试。安装成功后重新打开应用,恢复更新前网关的运行或停止状态。

## Consequences

- 更新包必须验证发布方签名,签名私钥不得随应用分发。发布物须包含可安装程序、对应的校验签名和更新信息,单独发布源码标签或旧式 ZIP 不构成可用更新。
- 现有不含更新功能的 ZIP 版须先手动安装一次具备更新能力的版本,之后才能应用内升级。
- 自有代码的开源分发采用 [ADR-0007](0007-mit-open-source-distribution.md) 确定的 MIT 许可证,第三方内容保留其原有许可;开源核查和发布准备不因本决策而省略。
