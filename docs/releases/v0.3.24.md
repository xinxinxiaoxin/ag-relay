# AG Relay v0.3.24

## 搜索阶段的限流在网关内恢复

Codex 和 Claude 在网页搜索或思考途中遇到临时限流时，网关会保留内部重试机会，避免仅因搜索已经完成就把失败抛给客户端、连续耗掉重连次数。

正文前的已知思考、搜索进度和搜索结果继续缓冲；正文或客户端执行工具开始后仍即时流式下发。成功轮的内容完整保留，失败轮不显示。思考和搜索进度会晚一点出现。

覆盖 Codex／Claude Responses 和 Claude 原生 Messages；客户端身份、历史处理和缓存键保持既有规则。

## 总重试预算默认恢复为 300 秒

原默认值为 500 秒，常规发送上限仍为 110 次。取消、缓冲容量及已有恢复上限继续生效，不截断仍有正常生成进展的长回复。

已交付的正文和客户端工具不重放；明确的完成／不完整终态与额度错误保持原语义。
