# AG Relay v0.3.5

## 请求进展更直观

- 首页改为紧凑控制条与表格，直接查看请求最近阶段、耗时、尝试次数和距上次内容进展的时间。
- 最近活动与诊断日志按列展示时间、请求编号、级别、事件、尝试次数、HTTP 状态及简短原因。点击请求编号筛选关联记录，详细说明按需展开。
- 明确区分“上游已响应”与“回复完整结束”，不再将 HTTP 200 当作流式回复完整成功的依据。
- 精简关闭窗口提示，保留取消、留在托盘及安全退出操作。

## 重试与取消修复

- 修复客户端在等待重试时取消后，仍可能多发一次上游请求的问题；取消会及时结束等待并释放请求。
- 补齐普通响应、JSON 错误体与流式响应对明确无效错误的处理，减少无意义重试。
- 保留限流、临时故障、部署缺失及原有安全兼容修复的恢复能力；已传回内容后不会重新生成整条回复。

## 速度与兼容

- 不改重试次数、间隔和超时参数，不新增 token 用量或 tok/s 采集，不增加逐块写盘或额外上游请求。
- 旧核心缺少请求详情时显示未知，不伪造数据或预计完成时间。

## 安装与验证

- Windows x64：一般用户选择 `ag-relay_0.3.5_x64-setup.exe`；需要 MSI 的用户选择 `.msi`。
- 已通过隔离核心回归、界面测试与发布物签名校验。安装包未在维护者正在使用的网关环境执行安装或升级。
- 更新请等当前请求结束后进行；本次发布操作不会自动替换或重启现用网关。
