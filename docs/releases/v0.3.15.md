# AG Relay 0.3.15

## 减少 Codex 因空占位后的限流而反复重连

- 修复上游只发出空的“开始思考／开始回复”占位事件时，网关就提前放行的问题。尚未产生真正内容时，后续限流继续由网关内部重试，不再因此直接漏给 Codex。
- 空消息、空推理、空正文块和空拒绝块都按上述规则处理；正常成功的流内容完整保留，不删除或改写占位事件。
- 真正的文字、思考内容或工具调用已经交付后，仍然不重放整条请求，避免重复输出或执行工具。此时才出现的上游失败，仍需由客户端恢复。
- 保持重试次数、等待时间、历史兼容策略和连接设置不变。

## 使用提醒

- 本次修复减少的是“还没真正输出就报错”的无谓重连，不会消除上游本身的限流。
- 请等当前任务结束后再通过应用内更新升级；安装器不会强行结束正在工作的网关。
