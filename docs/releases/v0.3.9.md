# AG Relay 0.3.9

## 重试与剥离策略可以自己调整了

- 侧栏新增「重试与剥离」页面，分别管理 **Codex** 和 **Claude / Zcode** 两套 Responses 策略。
- 可调整常规尝试次数、起始等待、最长等待、总时间预算，以及明确历史错误的确认次数。
- 从模块库添加或移除处理项。每个模块都会说明专业字段、实际处理内容、触发条件和可能的影响，不需要手写字段表达式。
- 历史兼容模块支持「报错后处理」或「提前处理」。新增的有损提前处理默认不启用，开启前会显示影响确认。
- 支持恢复本组或全部策略默认。恢复默认先填入草稿；保存不会中断请求，需要明确选择安全重启才会应用到运行中的网关。
- 页面区分草稿、已保存和运行中配置；旧核心无法确认运行策略时，不会误报已经生效。

## 历史兼容与保护

- Codex 的历史推理及相关编号按完整组合处理，保留可验证的搜索内容与工具输入输出，避免只删一半造成新的关联错误。
- 提前处理遇到服务端历史引用、未知类型或不完整工具配对时，保留原始请求；后续空回应与历史错误也不会绕过该保护进行局部剥离。
- 限流、空回应和明确历史错误分别处理，不用限流错误作为删除旧推理的理由。
- 关闭历史模块后，会话记忆不能绕过关闭项；Codex 与 Claude / Zcode 的兼容记忆保持隔离。

## 使用提醒

- 剥离只修改转发副本，不删除本地聊天记录，但有损处理可能丢失旧推理连续性。
- 常规尝试次数包含首次发送，仍受总时间预算及特定恢复限制约束，不保证每次都会试满。
- 升级前请通过旧版的退出功能有序停止应用与网关；安装器不会替你强行结束正在工作的实例。
