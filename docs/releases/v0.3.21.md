# AG Relay v0.3.21

## 修复 Claude 和 Codex 思考阶段的断流恢复

模型还没有给出可见内容时，上游有时会先返回加密思考，再停止发送数据或提前结束。网关现在会缓冲这部分不可见的推理，在出现可见思考摘要、正文或工具调用之前，仍可按原有预算重试。

成功后，缓冲的事件按原顺序完整下发；失败轮次的内部思考不会混入成功响应。持续产生的新思考沿用流式等待，重复推理和心跳不会无限延长等待。

## 交付与结束边界

- 可见思考摘要、正文、客户端工具及已经完成的搜索交付后，仍不自动重放整轮请求。
- 上游明确返回的完成、不完整终态保持原语义。
- 沿用现有重试次数、时间预算、取消和缓冲容量限制。
- 仅作用于明确识别的 Claude/Codex Responses 请求，其他客户端及接口维持原行为。

## 发布流程

更新包使用独立验签工具，减少发布时重复编译主应用的等待。

## 已知限制

上游持续不可用、超过重试预算，或已经交付可见内容后断流时，客户端仍可能收到错误。本次更新不会改变模型服务本身的可用性。
