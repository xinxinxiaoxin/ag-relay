# AG Relay v0.3.22

## 修复多代理对话的历史恢复

带有代理间消息的对话遇到跨资源历史错误时，现在可以执行历史兼容处理，不再因不认识 `agent_message` 而拒绝整份历史、重复发送后报错。适用于 Codex，以及经 Responses 通道转发的 Claude。

- 完整保留代理消息正文、发送方、接收方和附加信息，仅在历史兼容处理时移除顶层资源编号。
- 旧推理按原有错误后策略处理；专用历史恢复与未覆盖错误保底都支持代理消息。
- 历史确实不完整、无法自动处理时，五次重试耗尽的提示会附上拒绝修复的具体原因。

## 处理边界

正常首发、重试次数、时间预算、会话身份、缓存键及工具配对保持原有规则。不会删除本地聊天记录；缺少消息正文、服务端引用和不完整工具历史仍保留，不强行丢弃。

已验证跨资源错误、未覆盖错误保底及相邻历史保护。上游接受情况仍取决于实际服务，历史兼容处理不保证所有会话都能恢复。
